# Módulo 05 — Arquitetura de Sistemas

Repositório de estudo da pós-graduação **Java Applied Engineering**.

## Organização

- `main`: anotações consolidadas das aulas, decisões e referências;
- `modulo-01-arquitetura`: práticas, diagramas e exemplos construídos durante o módulo.
- `feat/<tema>`: experimentos pontuais derivados da branch do módulo; integrar por PR quando representarem uma prática completa.

## Acompanhamento

- [GitHub Project — Pós: Módulo 05](https://github.com/users/luis-jagella/projects/2): visão do fluxo de estudo;
- [Milestone do módulo](https://github.com/luis-jagella/java-pos-modulo-05/milestone/1): entrega completa da disciplina;
- as issues agrupam o conteúdo em blocos de aulas, prática de diagramas e revisão para avaliação.

### Fluxo de trabalho

1. Escolher a issue atual no Project e movê-la para **Em andamento**;
2. Registrar a síntese da aula na `main`;
3. Quando houver prática, desenvolver na `modulo-01-arquitetura` ou em uma `feat/<tema>`;
4. Relacionar commits/PRs à issue e movê-la para **Concluído** após revisão.

## Conteúdo do módulo

1. Introdução
2. Pensamento Arquitetural
3. Modularização
4. Características Arquiteturais
5. Pensamento Component-Based
6. Fundamentos de Estilos Arquiteturais
7. Arquitetura em Camadas e Arquitetura Pipeline
8. Arquitetura Microkernel e Arquitetura Baseada em Serviços
9. Arquitetura Event-Driven
10. Arquitetura Space-Based
11. Arquitetura Microservices
12. Escolhas, Decisões e Riscos
13. Clean Architecture

## Objetivo

Entender como avaliar trade-offs arquiteturais e escolher estilos adequados aos requisitos de um sistema — considerando modularidade, escalabilidade, disponibilidade, complexidade, custo e evolução.
